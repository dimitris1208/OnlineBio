This project is a **fully functional e-commerce website** built with **WordPress** and **WooCommerce**, featuring a clean and responsive design using custom **CSS** and **PHP** tweaks.

![Homepage](/projects/wordpress-eshop/homepage.jpg)

It supports **Stripe** for secure online payments and offers a seamless checkout experience.

![Checkout](/projects/wordpress-eshop/checkout.jpg)

In addition to the website, I developed a **Python synchronization script** hosted on a **Droplet server**.  
This script automatically fetches and updates product data from a wholesaler, ensuring the online store always displays up-to-date prices, availability, and descriptions.

![Script](/projects/wordpress-eshop/mapping.png)

The combination of a dynamic backend and a smooth shopping experience provides a **reliable and automated online store solution**.
