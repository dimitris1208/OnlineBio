This project is a **custom-built ERP system** developed by my team and me to streamline internal operations for medium-sized businesses.  
It provides **comprehensive management tools** for **stock**, **orders**, and **employees**, enabling end-to-end control over daily workflows.

![ERP](/projects/erp/erp.jpg)

The system allows administrators to monitor **inventory levels**, **process and track orders**, and manage **employee tasks and delivery schedules** — including marking when each order is delivered.

Built with **Python Flask** and **MongoDB**, it features a **RESTful architecture**, **GridFS** for file storage, and a responsive front-end using **HTML, CSS, and JavaScript**.  
Its modular design allows for easy scalability and integration with external services.

This ERP serves as a **complete business management solution**, combining robust backend logic with a clean and practical interface.
